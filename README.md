# Название проекта
SkyPro_Java_Diploma_Project

## Описание проекта
Данный проект представляет собой веб-приложение, позволяющее пользователям 
регистрироваться, авторизовываться и взаимодействовать с объявлениями и комментариями. 
Приложение реализует функционал для работы с объявлениями: создание, редактирование и удаление, 
а также позволяет пользователям оставлять комментарии к объявлениям.

## Установка и запуск
1. Клонируйте репозиторий
2. Перейдите в директорию проекта
3. Настройте базу данных PostgreSQL и создайте новую базу данных.
4. Обновите файл application.properties с вашими данными для подключения к базе данных.
5. Запустите приложение

## Функционал
### Регистрация и авторизация
- Пользователи могут зарегистрироваться и авторизоваться в приложении.
- Возможность смены пароля.

### Работа с объявлениями
- Получение списка всех объявлений.
- Получение информации об одном объявлении.
- Создание нового объявления.
- Редактирование и удаление своего объявления.

### Работа с комментариями
- Получение списка комментариев к объявлению.
- Создание нового комментария.
- Редактирование и удаление своего комментария.

### Система доступов
- Неавторизованные пользователи могут просматривать объявления.
- Авторизованные пользователи могут создавать, редактировать и удалять свои объявления и комментарии.
- Пользователи не видят чужие объявления в своем профиле.
